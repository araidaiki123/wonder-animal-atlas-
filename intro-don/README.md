# イントロどん 🎵

スマホ1台で、外でも遊べる「早押しイントロクイズ」アプリ（PWA）。
コンビニの入店音、お店の来店曲、駅の発車メロディ、CMソングなど、身近な「あの音」でイントロどん。

- ビルド不要の静的サイト（HTML / CSS / ES Modules）。GitHub Pages でそのまま公開できます。
- ホーム画面に追加すればアプリとして起動。アプリ本体とお題リストは圏外でも開けます。
- 音源はアプリに同梱していません（著作権のため）。**YouTube の URL 貼り付け／端末の音声ファイル／その場で録音**の3方式で、自分のセットに音源を取り込んで遊びます。
  - 「お店の来店曲」は、買い物のついでに店内で録音してセットを作るのが一番盛り上がります。

## 遊び方

1. ホームでお題セットを選ぶ（同梱セット or 自作セット）。
2. 「複製して編集」で問題ごとに音源を設定（YouTube URL / ファイル / 録音）。音源なしでも「別アプリで再生」モードで遊べます。
3. 人数・名前・モードを決めてスタート。
   - **きがるモード**：得点なし、人数登録なし。「どん！」で流す → 分からなければもう一度「どん！」（少し長く流れる）やヒント → 「答えを見る」→ 次へ、を繰り返すだけ。1人でも、車やピクニックでみんなで聴きながら口頭で当てる用途に。ホームの各セットの「🎧 聴く」を押すと設定画面を飛ばしてすぐ始まります（シャッフル・全問）。
   - **司会モード**：司会が「どん！」→ 答えが出たら「ストップ」→ 正解者をタップ。
   - **早押しモード**：スマホを机の真ん中に置き、画面が人数分の早押しボタンに分かれます。最初に押した人が解答権。司会が ○ / × を判定。
4. 再生回数が少ないほど高得点（1回目 3点・2回目 2点・3回目以降 1点、変更可）。毎回「頭から」少し長く流れます。
5. 結果画面から順位を共有できます（きがるモードは聴いた曲のリストを共有）。

## 公開手順（GitHub Pages）

1. GitHub のリポジトリ → **Settings → Pages** → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
2. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/intro-don/` で開けます。
3. iPhone は Safari の共有 → 「ホーム画面に追加」、Android は Chrome のメニュー → 「アプリをインストール」。

HTTPS で配信されていれば Service Worker が有効になり、2回目以降は圏外でもアプリが開きます。

**更新をデプロイするときは、必ず `intro-don/sw.js` の `VERSION`（例：`v1.2.0` → `v1.2.1`）を上げてから push してください。** Service Worker はアプリ本体を丸ごとキャッシュしているため、`VERSION` を上げないと既にインストール済みの端末には新しいファイルが届きません（`VERSION` を上げると、次に開いたときに「新しいバージョンがあります」と表示され、再読み込みで更新されます）。

## 開発

```bash
# 単体テスト（Node 22）
node --test intro-don/tests/*.test.mjs

# ローカルで動かす（リポジトリのルートで）
python3 -m http.server 8000
# → http://localhost:8000/intro-don/
```

設計の詳細は [ARCHITECTURE.md](./ARCHITECTURE.md)、お題の追加候補は [data/CATEGORY_IDEAS.md](./data/CATEGORY_IDEAS.md) を参照。

## お題セットの自作・共有

- セット編集画面から JSON で書き出し／読み込みができます（YouTube の音源指定は JSON に含まれます。端末ファイル・録音の音源は端末内にしか保存されないため、JSON には含まれません）。
- 同梱セットを書き出すと id は `user-<元の id>`（例：`konbini-chime` → `user-konbini-chime`）になります（自作セットとして取り込まれ、同梱セットとは衝突しません）。
- JSON の形式は ARCHITECTURE.md の第3章のとおりです。
- お題セット（`data/sets/*.json`）を追加・修正して公開するときも、上の「公開手順」のとおり `sw.js` の `VERSION` を上げてください。
